# DropSpot 📦

**DropSpot** is a modern, lightweight, and responsive web application designed for fast and seamless cloud file drops, media storage, and document management.

🔗 **Live Application:** [https://dropspot-0.web.app/](https://dropspot-0.web.app/?utm_source=gemini)

## ✨ Features

* 🔐 **Flexible Authentication**: Sign in using Google OAuth or create an account with Email and Password powered by Firebase Auth.

* 📤 **Drag-and-Drop File Uploads**: Upload multiple files of any type (PDFs, Audio, Video, Code, Images, and Documents) with real-time upload speed, size calculation, and progress indicators via Cloudinary.

* 📱 **Interactive Gallery & Gesture Controls**:

  * **Swipe Left**: Quick file deletion.

  * **Swipe Right**: Pin important files to the top.

  * **Auto-Categorization**: Automatic file icon and preview generation based on MIME types.

* 👁️ **In-App Media & Document Viewer**: Preview images, watch videos, listen to audio files, or read PDFs and code directly inside the browser.

* 🔒 **Privacy & Auto-Delete**: Optional setting to automatically delete file records after downloading.

* ⚙️ **Account Management**: Update your display name, send password reset emails, or manage preferences easily.

* 🎨 **Responsive Glassmorphism UI**: Mobile-first design with smooth CSS animations, dark-overlay modal sheets, and toast notifications.

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid, Glassmorphism, Animations), Vanilla JavaScript (ES6+)

* **Authentication**: Firebase Auth (Email/Password & Google Sign-In)

* **Database**: Firebase Realtime Database

* **Storage**: Cloudinary API (Multipart Uploads with progress tracking)

* **Hosting**: Firebase Hosting

## 📖 Usage Guide

1. **Sign Up / Log In**: Create an account using email/password or proceed with Google.

2. **Upload Files**: Switch to the **Upload** tab. Drag & drop your files into the box or click **Browse files**, then hit **Upload files**.

3. **View & Manage**: Go to **My Files** to view uploaded items.

   * Click on any thumbnail/row to open the file viewer.

   * Click **⬇ Save** to download.

   * Swipe left on mobile/desktop to delete or right to pin.

4. **Settings**: Click the gear icon (⚙️) in the top-right corner to toggle **Auto-delete after download**, change your name, or request a password reset.
